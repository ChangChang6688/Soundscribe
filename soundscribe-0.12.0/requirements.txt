# ═══════════════════════════════════════════════════════════
#  声文 SoundScribe · 运行依赖（基础版 = CPU）
# ═══════════════════════════════════════════════════════════
#
#  ★ Windows / macOS / Linux 通用。装完即可用 **CPU** 跑全部四个引擎：
#      SenseVoice(中文) · Parakeet(英文) · Moonshine(英文轻量) · Whisper(通用)
#
#  ★ 为什么基础版不带 CUDA：
#      sherpa-onnx 的 pip 包默认是 **CPU-only 编译**，装了显卡也用不上；
#      而 CPU 上的 SenseVoice 已有 60×+（1 小时录音约 1 分钟），
#      对"打开就能用"这个目标来说完全够。
#      真正需要 GPU 的只有 Whisper（它在 CPU 上只有约 4.7×）——
#      想让它走显卡，再叠加装 requirements-gpu.txt。
#
#  ★ 安装（建议在虚拟环境里）：
#      python -m venv .venv
#      .venv/Scripts/pip install -r requirements.txt      # Windows
#      .venv/bin/pip     install -r requirements.txt      # macOS / Linux
#
#  ★ 另外还需要一个 **ffmpeg**（不在 pip 里）：
#      Windows : 把 ffmpeg.exe / ffprobe.exe 放进 PATH，或放到项目 runtime/ 下
#      macOS   : brew install ffmpeg
#      它负责抽音轨与静音切段，缺了会在"探测媒体信息"这一步报错。
#
#  ★ 版本刻意钉死：这套组合是实测跑通的（见 tools/release_check.py）。
#      升级前先跑一遍那个检查，别直接改版本号。
