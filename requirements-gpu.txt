# ═══════════════════════════════════════════════════════════
#  声文 SoundScribe · 可选：GPU 加速（仅 NVIDIA 显卡 + Windows/Linux）
# ═══════════════════════════════════════════════════════════
#
#  安装：pip install -r requirements-gpu.txt
#        （会先装基础依赖，再加下面这些 NVIDIA 运行库）
#
#  ★ 装了它之后，**Whisper 会自动走显卡**（实测 70× vs CPU 的 4.7×，差 15 倍）。
#    不需要任何额外设置 —— app/pipeline/engines.py 里会探测显卡是否存在。
#
#  ★★ 但 **sherpa-onnx 的三个引擎不会因此变快**：
#     它的 pip 包是 CPU-only 编译，传 provider='cuda' 也只会静默回落 CPU。
#     所以这份文件的实际收益就是 Whisper 那一条。
#     要不要装，取决于你转不转中英夹杂/英文素材（那些才会用到 Whisper）。
#
#  ★ 体积代价：约 2 GB（cublas 736MB + cudnn 1092MB + nvrtc 178MB）
#    —— 如果只想让同事"打开就能用"，基础版就够了，不必给这一份。
#
#  ★ macOS 用户不需要这个文件：Apple 平台统一走 CPU
#    （CoreML 通道无法可靠探测，猜错会静默回落成"假 GPU"，不如不用）。
#
#  ★ 这三个包只是 **运行库**，不用装完整的 CUDA Toolkit。

-r requirements.txt

nvidia-cublas-cu12==12.9.2.10
nvidia-cudnn-cu12==9.26.0.51
nvidia-cuda-nvrtc-cu12==12.9.86
